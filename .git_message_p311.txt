P3.1.1 (2026-09-22): FilterDialog parameter UI (8 kinds with sliders/spinboxes)

Replace P0-5 simplified dialog (label-only "参数: ...") with PS-style
per-FilterKind parameter widgets:
  - int slider + QSpinBox (ksize / d / level / levels / threshold / density)
  - double slider + QDoubleSpinBox (sigma / sigmaColor / sigmaSpace /
    amount / radius / HighPass radius)
  - placeholder label "(无参数)" / "(固定参数)" for non-param filters
  - Snap-to-odd for ksize (1..31)
  - Live paramText refresh on every slider drag

Root cause: P0-5 (2026-09-10) FilterDialog only showed a static
paramText() — no way to actually edit filter parameters from UI.
Strategy classes already expose the public fields (ksize/sigma/...);
only the dialog needed wiring.
