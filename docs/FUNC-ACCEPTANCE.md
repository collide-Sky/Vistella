# 完整功能链验收清单（模板与说明）

> **依据**：`docs/CONTRACTS.md` §4。
> **用法**：每个功能/阶段开始时复制本模板到 `docs/acceptance/<阶段号>-<功能名>.md`，逐项填写，随代码一起提交。
> **硬规则**：
> - **每一项都要填**。不适用的写「不适用 + 理由」，**不允许留空**。
